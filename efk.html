EFK Stack Architecture

Elasticsearch, Fluentd, Kibana

EFK Stack là một nền tảng mã nguồn mở để thu thập, lưu trữ và phân tích log. Kiến trúc này giúp các tổ chức quản lý và phân tích lượng lớn dữ liệu log một cách hiệu quả.

Nguồn Log

📱
Ứng dụng
Log từ ứng dụng web, mobile, microservices
🖥️
Hệ thống
Log từ OS, hệ thống tệp, security events
🌐
Mạng
Log từ network devices, firewall, load balancer
📊
Cơ sở dữ liệu
Log từ MySQL, PostgreSQL, MongoDB, Redis
↓

Thu thập & Xử lý Log

🔄
Fluentd
Công cụ thu thập log mã nguồn mở, xử lý và chuyển đổi dữ liệu log từ nhiều nguồn
Input Plugins
Nhận log từ file, HTTP, TCP, syslog, Docker, Kubernetes
Filter Plugins
Phân tích cú pháp, làm sạch, chuyển đổi định dạng log
Output Plugins
Gửi log đã xử lý đến Elasticsearch hoặc các đích đến khác
↓

Lưu trữ & Indexing

📦
Elasticsearch
Công cụ tìm kiếm và phân tích phân tán, lưu trữ log được index để tìm kiếm nhanh
Cluster
Kiến trúc phân tán với nhiều node để đảm bảo tính sẵn sàng cao
Sharding
Chia dữ liệu thành các shard để phân phối tải và tăng hiệu suất
Replication
Sao chép dữ liệu để đảm bảo độ tin cậy và khả năng phục hồi
↓

Hiển thị & Phân tích

📈
Kibana
Giao diện web để tìm kiếm, visualize và quản lý dữ liệu trong Elasticsearch
Discover
Tìm kiếm và lọc log theo thời gian thực
Visualize
Tạo biểu đồ, bảng điều khiển từ dữ liệu log
Dashboard
Tổng hợp nhiều visualization vào một màn hình

Lợi ích của EFK Stack

Khả năng mở rộng

Kiến trúc phân tán cho phép mở rộng theo chiều ngang để xử lý khối lượng log lớn

Hiệu suất cao

Tìm kiếm và truy vấn log gần như thời gian thực nhờ Elasticsearch

Linh hoạt

Hỗ trợ nhiều định dạng log và nguồn dữ liệu khác nhau

Mã nguồn mở

Giảm chi phí triển khai và bảo trì so với các giải pháp thương mại
