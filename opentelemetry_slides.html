Khái niệm OpenTelemetry

OpenTelemetry (OTel) là một framework mã nguồn mở, vendor-neutral để thu thập, xử lý và xuất dữ liệu telemetry từ các ứng dụng và hệ thống (metrics, logs, và traces).

🎯 Mục tiêu chính:

  • Cung cấp một bộ API và SDK chuẩn cho các ngôn ngữ lập trình
  • Thu thập telemetry data: Traces, Metrics, Logs
  • Độc lập với vendor - tương thích với nhiều backend khác nhau
  • Tích hợp dễ dàng vào ứng dụng hiện tại

💡 Lợi ích:

  • Giảm độ phức tạp trong việc triển khai observability
  • Không bị lock-in với một vendor cụ thể
  • Cộng đồng lớn và được hỗ trợ bởi CNCF

Cách triển khai OpenTelemetry

1️⃣ Manual Instrumentation

Tự code để tạo spans, metrics trong ứng dụng

tracer.startSpan("operation-name")
meter.createCounter("request.count")

2️⃣ Automatic Instrumentation

Sử dụng libraries có sẵn để tự động capture data từ frameworks phổ biến (Express, Django, Spring...)

3️⃣ Triển khai Collector

  • Chạy như sidecar container hoặc daemon
  • Cấu hình receivers, processors, exporters
  • Scale theo nhu cầu của hệ thống

4️⃣ Kết nối với Backend

Cấu hình exporters để gửi data đến Jaeger, Prometheus, Grafana Tempo, hoặc các giải pháp thương mại như Datadog, New Relic...
